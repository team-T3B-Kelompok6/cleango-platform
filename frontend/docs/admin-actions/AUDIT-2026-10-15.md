## Yang dicoba

- Layanan: membuat paket, membaca detail, mengubah nama dan harga promo menjadi Rp90.000 dari harga dasar Rp100.000, lalu menghapus record uji melalui dialog konfirmasi.
- FAQ: membuat pertanyaan, membaca detail, mengubah jawaban dan status publikasi menjadi Nonaktif, membaca ulang hasilnya, lalu menghapus record uji.
- Petugas: menambah petugas dengan dua keahlian, membaca detail, mengganti keahlian dan status menjadi Masa Training, membaca ulang hasilnya, lalu menghapus record uji. Form memakai Keahlian petugas.
- Customer: menambah customer manual, membaca detail, mengganti alamat dan status akun menjadi Nonaktif, membaca ulang hasilnya, lalu menghapus record uji.
- Pesanan: record uji disiapkan melalui API preview sebagai data masuk dari pelanggan. Menugaskan Budi Santoso menghasilkan status Menunggu Lokasi dan tombol Pantau Petugas. Detail kemudian diubah ke Sedang Dikerjakan dengan jam dan catatan baru. Hasil dibaca ulang sebelum record dihapus.
- Jadwal: record uji disiapkan melalui API preview. Tanggal, jam, dan status diubah; hasil dibaca ulang sebelum record dihapus. Jadwal pindah ke shift yang mengikuti jam pengerjaan.

Dialog hapus pada semua menu menampilkan nama dan ID record yang akan dihapus. Browser menampilkan pesan sukses setelah simpan/hapus. Tombol, form, Server Action, dan pembacaan hasil tersimpan diuji dalam alur yang sama.

Hasil terstruktur ada di [ui-crud-2026-10-15.json](ui-crud-2026-10-15.json). [Screenshot sesudah penghapusan jadwal uji](jadwal-delete-2026-10-15.png) menunjukkan pesan sukses dan daftar kembali tanpa record sementara.

## Pemeriksaan pendukung

- Roundtrip Server Actions enam resource melalui API preview: lolos. Create pesanan dan jadwal ditolak.
- Validasi harga/foto/fasilitas, respons penyimpanan foto/promo/keahlian, dan penugasan: lolos.
- TypeScript, format kode, dan `git diff --check`: lolos.
- Error konsol browser selama pengujian: tidak ada.

## Batas integrasi

Ini membuktikan alur frontend terhadap API preview, belum alur database Express sampai aplikasi mobile. `origin/main` diperiksa ulang dan masih pada commit `192c4d9`. Backend tersebut belum menyediakan mutation pesanan serta endpoint jadwal/customer yang digunakan frontend. Kontrak petugas masih memerlukan wilayah, sementara frontend memakai keahlian. Foto/promo layanan, kategori dinamis, upload, dan banner juga memerlukan penyesuaian API tim.
