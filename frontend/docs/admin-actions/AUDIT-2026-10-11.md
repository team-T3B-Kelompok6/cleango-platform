# Audit frontend — 11 Oktober 2026

Audit mengikuti tugas Express + Next.js serta PRD di folder induk repositori. Lingkup pekerjaan adalah frontend web admin. Backend dan aplikasi mobile dikerjakan anggota lain.

## Aksi yang tersedia

| Menu | Hasil pemeriksaan |
| --- | --- |
| Pesanan | Assign, read, update, delete. Tidak ada create. |
| Jadwal | Read, update melalui halaman detail, delete. Tidak ada create. |
| Layanan | Create, read, update, delete. |
| FAQ | Create, read, update, delete. |
| Customer | Read, update melalui halaman detail, delete; create manual tersedia. |
| Petugas | Create, read, update, delete. |

Tombol create mengikuti konfigurasi resource. Route `/pesanan/new` dan `/jadwal/new` menghasilkan 404; Server Action juga menolak create untuk kedua resource tersebut. Mutasi memakai API, bukan hanya perubahan state browser.

## Pemeriksaan ulang

- Login admin/admin berhasil melalui Server Action dan API preview lokal.
- Keenam menu lolos 24 pemeriksaan layout pada 1280×820, 768×1024, 360×800, dan 800×360, tanpa overflow horizontal halaman.
- Detail, form ubah, dan dialog hapus dibuka pada semua menu. Footer form tetap di dalam dialog. Penghapusan dibatalkan sehingga data awal tidak berubah.
- Form tambah layanan, FAQ, customer, dan petugas dapat dibuka. Validasi penugasan tanpa petugas menampilkan pesan yang sesuai.
- Build produksi, TypeScript saat build, dan Prettier lolos. Tidak ada error/warning pada browser selama pemeriksaan.
- Pemeriksaan kode mengonfirmasi App Router/RSC, dynamic route dengan awaited params, metadata, next/link, next/font, next/image, CSS variables, server-only API layer, pemeriksaan res.ok, useActionState, useFormStatus, validasi server, revalidatePath, redirect, serta loading/error/404.
- Git melacak `.env.example` untuk kedua folder; `.env.local` dan node_modules diabaikan. PRD dan dokumen tugas berada di luar repositori kode.

## Batas kesiapan pengumpulan

Frontend menyediakan seluruh aksi yang diminta. Pengujian memakai API preview terpisah di luar repositori. Backend repo masih hanya menyediakan health endpoint dan database.sql masih berupa placeholder. Karena itu, login/mutasi pada Express serta penyimpanan MySQL/MariaDB belum terverifikasi. Sebelum pengumpulan tim perlu menghubungkan API nyata, menyediakan schema/seed, dan mengulang pengujian integrasi.

Tracking tetap simulasi sesuai permintaan. Administrasi GitHub/PR, Trello, data kelompok, dan presentasi perlu dipastikan oleh tim; audit lokal ini tidak memeriksa atau mengubah layanan tersebut.

PRD diperbarui agar struktur folder, batas create, dan tabel endpoint tidak lagi merujuk rancangan lama.
