## Tujuan

AI-01 memprediksi sisa waktu perjalanan cleaner. GPS hanya mengirim posisi; OSRM menghitung rute, jarak tersisa, dan ETA dasar; model regresi mencoba memperbaiki ETA dasar tersebut.

## Alur sistem

1. Flutter atau dashboard mengirim koordinat cleaner dan tujuan ke Express.
2. Express memanggil OSRM untuk memperoleh rute, jarak tersisa, dan durasi dasar.
3. Express membentuk fitur yang hanya tersedia pada waktu prediksi: waktu, durasi perjalanan yang sudah berlalu, lama berhenti, rasio jarak, dan rasio kecepatan.
4. Layanan Flask memuat pipeline Joblib dan menghasilkan ETA ML tanpa melatih ulang model.
5. Express memakai ETA ML hanya bila evaluasi artefak menyatakan model mengalahkan baseline training. Jika layanan AI mati, model belum siap, atau model tidak lebih baik, Express mengembalikan ETA OSRM.
6. Flutter dan dashboard menampilkan ETA, sumber prediksi, dan waktu pembaruan terakhir.

Koordinat pelanggan tidak menjadi fitur model. ID perjalanan dianonimkan dan pemisahan data dilakukan per perjalanan berdasarkan waktu agar titik GPS dari perjalanan yang sama tidak bocor ke split lain.

## Kontrak model

Target regresi:

```text
actual_remaining_seconds
```

Fitur:

```text
baseline_eta_seconds
elapsed_seconds
stopped_duration_seconds
distance_ratio
rolling_speed_ratio
eta_elapsed_ratio
hour_sin
hour_cos
weekday_sin
weekday_cos
```

Model yang dibandingkan:

- Linear Regression
- Ridge Regression
- Decision Tree Regressor
- Random Forest Regressor

Pemilihan model menggunakan MAE validasi terendah, kemudian RMSE sebagai pemecah seri. Data test hanya digunakan satu kali setelah pemilihan. Laporan juga memisahkan error untuk kondisi bergerak/berhenti dan jarak dekat/sedang/jauh.

## Artefak

Setelah menjalankan `python train_eta.py`:

```text
artifacts/eta_v1/
├── eta_pipeline.joblib
├── metrics.json
└── model_info.json
```

`eta_pipeline.joblib` berisi preprocessing dan model terpilih. `metrics.json` menyimpan MAE/RMSE tiap kandidat, baseline, hasil test, kondisi perjalanan, jumlah baris, serta jumlah perjalanan tiap split.

## Endpoint

### Flask internal

- `GET /health`
- `POST /predict/eta`

### Express utama

- `POST /api/tracking/eta` — wajib token login.
- `POST /api/tracking/eta-preview` — hanya aktif pada development untuk demo Flutter yang autentikasinya masih lokal.

## Batasan klaim

Model ini adalah demo teknis. LaDe memberi pola perjalanan, tetapi jadwal CleanGo masih simulasi dan baseline historis belum berasal dari OSRM. Karena itu hasil tidak boleh disebut akurat untuk operasional nyata sebelum diuji ulang dengan data CleanGo di Indonesia.

## Hasil eksperimen saat ini

- Model terpilih: Linear Regression.
- Test MAE model: 1.587,68 detik.
- Test RMSE model: 3.247,70 detik.
- Baseline proxy MAE: 1.929,46 detik.
- Perbaikan MAE terhadap baseline proxy: sekitar 17,7%.
- Test set: 6.339 snapshot dari 198 perjalanan yang tidak muncul di train/validation.

Angka tersebut hanya membuktikan pipeline demo bekerja pada proxy LaDe. Angka itu bukan klaim akurasi ETA di Malang atau Indonesia.
